Verification checklist:

- MY only + selected tier enrolls only MY players in that tier.
- MY + SG + selected tier enrolls MY and SG players in that tier, not KH.
- Manual User ID can explicitly add a player outside the automatic country/tier filter.
- A player matching both automatic and manual targeting is enrolled once with source `both`.
- Excluded players are never enrolled.
- Tiered Deposit Reward creates fixed Credit levels in `campaign_levels`.
